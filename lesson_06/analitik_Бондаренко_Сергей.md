## Письмо 1. Ревью запросов

### Запрос 1. Заказчику нужны резюме с ожиданиями по зарплате от 100 000 ₽ и выше.

```js
db.resumes.find({ salary: { $gte: "100000" } })
```

- Решение: есть ошибка — значение не того типа: строка вместо числа или логического значения — верно
- Комментарий: Ошибка типа: salary хранится числом, а порог в запросе задан строкой. Это сравнение не находит нужные резюме, поэтому вывод коллеги неверен. Укажите числовой порог 100000.
- Исправленный запрос:

```js
db.resumes.find({ salary: { $gte: 100000 } })
```

### Запрос 2. Найти кандидатов с высшим образованием.

```js
db.resumes.find({ education: { level: "Высшее" } })
```

- Решение: есть ошибка — вложенный документ сравнивается целиком — нужна точечная нотация — верно
- Комментарий: Ошибка адресации вложенного поля: education задан целиком как точное значение объекта, поэтому запрос не находит документы с дополнительными полями. Фильтруйте по education.level.
- Исправленный запрос:

```js
db.resumes.find({ "education.level": "Высшее" })
```

### Запрос 3. Кандидаты, которые знают и SQL, и Python.

```js
db.resumes.find({ skills: { $in: ["SQL", "Python"] } })
```

- Решение: есть ошибка — не тот оператор для массива: $in вместо $all или наоборот — верно
- Комментарий: Ошибка логики: $in означает SQL ИЛИ Python, а заказчику нужны кандидаты со знанием обоих навыков. Используйте $all.

### Запрос 4. Кандидаты, которые проработали в Retail Lab не меньше 12 месяцев.

```js
db.resumes.find({ "experience.company": "Retail Lab", "experience.months": { $gte: 12 } })
```

- Решение: есть ошибка — условия на массив документов выполняются в разных элементах — нужен $elemmatch — верно
- Комментарий: Ошибка проверки элементов массива: условия experience.company и experience.months могут совпасть в разных местах массива. Используйте $elemMatch, чтобы обе проверки относились к одной записи о работе.

### Запрос 5. Открытые вакансии в Москве, где верхняя граница зарплаты не меньше 160 000 ₽.

```js
db.vacancies.find({ city: "Москва", is_open: true, "salary.to": { $gte: 160000 } })
```

- Решение: запрос верный — верно
- Комментарий: Запрос верный: фильтры по городу, статусу открытой вакансии и минимальной верхней границе зарплаты объединены через И, как требуется.

### Запрос 6. Все резюме на должности, в названии которых есть слово Python.

```js
db.resumes.find({ position: /python/ })
```

- Решение: есть ошибка — регистр букв: шаблон без флага i — верно
- Комментарий: Ошибка регистра: /python/ чувствителен к регистру и не найдёт название с Python. Добавьте флаг i, чтобы поиск не зависел от регистра букв.

### Запрос 7. Резюме с ожиданиями от 70 000 до 100 000 ₽ включительно.

```js
db.resumes.find({ salary: { $gte: 70000 }, salary: { $lte: 100000 } })
```

- Решение: есть ошибка — ключ в фильтре повторяется — первое условие пропадает — верно
- Комментарий: Ошибка повторяющегося ключа: в объекте фильтра salary объявлен дважды, поэтому первое условие $gte перезаписывается вторым $lte. Объедините оба оператора в одном объекте salary.

### Запрос 8. Финальные собеседования в московских компаниях, которые проходили по видеозвонку.

```js
db.interviews.find({ "company.city": "Москва", format: "видеозвонок", stage: "финальное" })
```

- Решение: запрос верный — верно
- Комментарий: Запрос верный: город компании, формат видеозвонка и финальный этап проверяются одновременно; это соответствует задаче.
